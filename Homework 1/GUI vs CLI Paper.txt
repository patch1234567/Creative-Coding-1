GUI and CLI are both methods of interacting with a computer system and completing actions such as creating and removing files. GUI stands for Graphical User Interface. GUI systems rely on visual menus to allow users to work with the system. A good example of GUI systems are the icons for files and applications that can be dragged and moved around the desktop and into other folders and storage organizers in the files app. CLI stands for Command Line Interface. CLI systems allow for users to complete the exact same actions as they're able to on GUI systems do all from the same window using commands. Each one of these methods of interaction with the computer has its pros and cons. For one, CLI is much quicker and more efficient but requires the user to already understand and be able to use command syntax and remember things like exactly what a specific file is called in order to access it. GUI on the other hand is much simpler and intuitive for the user overall, but is also much slower to execute due to the constant need to load new windows. I personally haven't had any experience with CLI so my preference right now is GUI, but I understand that could very well change over the length of this course.
